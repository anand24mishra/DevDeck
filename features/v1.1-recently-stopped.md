# v1.1 — Recently stopped and restart

## Goal (plain)
If I stopped something by mistake, bring it back in one click.

## Acceptance criteria
- [ ] Before any stop, capture: command, args (kept in memory + encrypted on disk only if user enables persistence), cwd, env keys only (no values), time
- [ ] "Recently stopped" list (last 20, cleared on quit by default)
- [ ] Restart runs the same command in the same cwd; shows success/failure
- [ ] Never restarts anything that was refused by the allowlist
- [ ] Secrets: args are masked in the UI; persistence is opt-in with clear wording

## Notes
Use `child_process.spawn` with `detached: true`, `stdio: 'ignore'`, `cwd`. Inherit a clean env from the user's login shell if possible;
document limits (processes started from special shells may not restart identically).
