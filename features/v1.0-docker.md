# v1.0 — Docker containers and live logs

## Goal (plain)
See my containers, start/stop/restart them, and read their logs live.

## Acceptance criteria
- [ ] Detect socket: `~/.docker/run/docker.sock`, `/var/run/docker.sock`, OrbStack, Colima; setting to override
- [ ] List containers with state, image, Compose project; group by Compose project
- [ ] Start / Stop / Restart per container; "Stop all containers" with confirmation
- [ ] Live logs: last 200 lines then follow; filter box; pause/resume; copy; clear
- [ ] Batch log IPC every 100 ms; renderer keeps at most 2000 lines (virtualize the list)
- [ ] TTY vs non-TTY containers both render correctly (demux for non-TTY)
- [ ] Streams closed when the panel closes, the container dies, or the window closes
- [ ] Clear messages for: Docker not installed, not running, permission denied

## Technical notes
dockerode `listContainers({all:true})`, `getContainer(id).logs({follow:true, stdout:true, stderr:true, tail:200})`,
`docker.modem.demuxStream(stream, out, out)` for non-TTY. `docker.getEvents()` to refresh on start/stop/die.

## Design notes
Log viewer uses the mono token, 12/1.5, selectable text, no wrapping by default with a wrap toggle.
State shown as dot + word.

## Out of scope
exec, image/volume cleanup, Compose up/down (v1.1).
