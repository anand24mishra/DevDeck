# v1.1 — Port-conflict fixer

## Goal (plain)
When a port is busy, tell me who has it and let me free it.

## Acceptance criteria
- [ ] Search box accepts ":3000" → shows owner (process or container) with project
- [ ] "Free port" stops the owner via the safe path; containers use Docker stop
- [ ] Optional: after freeing, run a chosen profile step ("kill and start mine")
- [ ] If owner is not allowlisted (e.g. system service), explain and offer nothing destructive

## Notes
Use listening-port data already collected; map Docker published ports to containers via `docker inspect`/list `Ports`.
