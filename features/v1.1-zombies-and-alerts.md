# v1.1 — Zombie detection and resource alerts

## Acceptance criteria
- [ ] Flag orphaned dev processes (ppid 1, or parent missing) older than a threshold, and containers idle for days
- [ ] Alert rules: CPU or memory over X for Y minutes (defaults conservative), per process or per project
- [ ] Native notifications with "Stop" action; snooze options; global mute
- [ ] Rate limiting: at most one notification per rule per hour; never during "Do Not Disturb" if detectable
- [ ] All thresholds editable in Settings; alerts off by default until the user enables them

## Notes
Evaluate rules in main on each poll using a sliding window. Test with fake clocks. Keep polling cost low.
