## Acceptance criteria
- [ ] AC-1: Lists allowlisted dev processes for current user with name, port(s), CPU %, memory (MB), uptime (human readable).
- [ ] AC-2: Groups processes by project root (traversing up from process `cwd` to nearest `.git` or `package.json` within `$HOME`). Fallback to "Ungrouped / Other" if no project detected or cwd null.
- [ ] AC-3: Skips any executable inside `.app/Contents/`, system binaries, root processes, DevDeck itself, and items in user ignore list.
- [ ] AC-4: Search bar filters in real-time across process name, port number, and project name.
- [ ] AC-5: Polling refreshes every 3 seconds by default (configurable: 2s, 3s, 5s, 10s).
- [ ] AC-6: Refreshes pause when window is hidden (`visibilityState === 'hidden'`) and guard against overlapping in-flight calls.
- [ ] AC-7: States:
  - Loading state shows quiet skeleton rows.
  - Empty state distinguishes "No dev processes running" from "No processes matching '<query>'".
  - Error state displays clean, actionable error message with manual Retry button.
- [ ] AC-8: Process row displays state text + indicator dot ("Running", never color alone).
- [ ] AC-9: "Details" disclosure toggles to show PID and command line (command line masked by default to protect secrets/tokens, with explicit reveal button).
- [ ] AC-10: Accessible: fully navigable via keyboard, visible focus rings, minimum 4.5:1 text contrast, respects `prefers-reduced-motion`.

## Risks
1. **Secret leakage in command lines**: `command` may contain API keys, DB passwords, or tokens.
   - *Mitigation*: Never log command lines. Mask command lines by default in the UI with a masked pill (`••••••••`) and explicit reveal toggle.
2. **Performance of `ps` + `lsof`**: Running `lsof` frequently could spike CPU.
   - *Mitigation*: Run `lsof` only for discovered PIDs, batch calls, pause polling when window is blurred/hidden, and drop intervals below 2s.
3. **Flaky cwd resolution**: Processes may terminate between `ps` and `lsof`.
   - *Mitigation*: Treat non-zero exit codes from `lsof` gracefully without failing the entire process list.
4. **Renderer security**: Renderer must never execute commands or access Node APIs.
   - *Mitigation*: Strictly enforce `contextIsolation`, read-only `window.api.getProcesses()` over IPC.

## Technical notes
```bash
ps -U "$USER" -o pid=,ppid=,pcpu=,rss=,etime=,command=          # rss is KB
lsof -a -d cwd -Fpn -p 123,456                                    # cwd per pid
lsof -iTCP -sTCP:LISTEN -nP -Fpn                                  # listening ports
```
- lsof exits non-zero when a pid disappears; treat stdout as valid.
- Get the executable name reliably (paths may contain spaces): parse `comm`/first token carefully and unit-test with a fixture that has spaces.
- `ProcessProvider` interface with a darwin implementation (see `docs/02-architecture.md`).
- Convert etime (`dd-hh:mm:ss`) to seconds in a pure function.

## Design notes
Group header = folder name + path in muted mono. Row = name, ports, cpu, mem, uptime, Stop button (quiet).
One primary action on the screen: "Stop all dev processes" is a quiet button; danger styling only inside the confirm dialog.
