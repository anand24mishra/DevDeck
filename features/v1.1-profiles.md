# v1.1 — Profiles: start/stop a whole project stack

## Acceptance criteria
- [ ] A profile = name, project root, list of steps (command, cwd, ready-check: port open or delay)
- [ ] Start runs steps in order, waits for each ready-check, shows progress; Stop stops in reverse order using the safe-kill path
- [ ] Create a profile from currently running processes ("Save this stack")
- [ ] Import/export profile as JSON (no secrets)
- [ ] Optional `.devdeck.json` in a project folder is auto-detected
- [ ] Failure at any step stops the sequence and explains why

## Notes
Steps run through the same process spawner as restart. Ready-check: TCP connect with timeout. Store in userData, validated by schema.
Design: a linear list with status dots per step; one primary "Start stack" button.
