# v1.0 — Safe kill (one, project, all)

## Goal (plain)
Stop a process, a whole project, or all my dev processes, without ever hurting anything else.

## Acceptance criteria
- [ ] Stop one process, stop project, stop all dev processes
- [ ] Confirm dialog states count and project name before anything happens
- [ ] SIGTERM first; after 3 s, SIGKILL only survivors; report which were forced
- [ ] Main recomputes targets and re-validates (allowlist, `.app` filter, ignore list, self-tree)
- [ ] PID-reuse guard: same pid + same start time/command, else `refused`
- [ ] Result toast: "Stopped 4, forced 1, skipped 0"; row updates without a full reload
- [ ] Keyboard: Enter confirms only when the Stop button has focus; Esc cancels
- [ ] Unit tests for every rule in `docs/04-safety-model.md`

## Technical notes
```ts
// escalation core: pure and injectable so it can be unit-tested with fake timers
export async function terminate(pids: number[], deps: KillDeps): Promise<KillReport> {
  const { ok, refused } = await deps.revalidate(pids)      // allowlist + same identity (pid, start time)
  ok.forEach((p) => deps.signal(p.pid, 'SIGTERM'))
  await deps.sleep(3000)
  const survivors = ok.filter((p) => deps.alive(p.pid))
  survivors.forEach((p) => deps.signal(p.pid, 'SIGKILL'))
  await deps.sleep(300)
  const stillRunning = survivors.filter((p) => deps.alive(p.pid)).map((p) => p.pid)
  const forced = survivors.map((p) => p.pid).filter((pid) => !stillRunning.includes(pid))
  const stopped = ok.map((p) => p.pid).filter((pid) => !survivors.some((s) => s.pid === pid))
  return { requested: pids, stopped, forced, refused, stillRunning }
}
```
`KillDeps` = `{ revalidate, signal, alive, sleep }`; real implementations wrap `process.kill`, `ps`, and `setTimeout`.

## Design notes
Danger color appears only on the confirm dialog's Stop button. Copy: "Stop 4 processes in api-server?"
Details line lists names, capped at 8, with "and 3 more".

## Out of scope
Restart (v1.1), sudo/root actions (never).
