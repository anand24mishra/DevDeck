# v1.1 — Docker extras

## Acceptance criteria
- [ ] Open a shell in a container (`docker exec`) — surfaces in the terminal when v2 lands; in v1.1 opens the user's Terminal.app with the command
- [ ] Compose project actions: stop / restart all containers of a project
- [ ] Cleanup: list dangling images, stopped containers, unused volumes with sizes; preview; second confirmation; then delete
- [ ] Never delete volumes attached to running containers; explain why something is excluded
- [ ] Show container CPU/memory (stats stream, throttled)

## Notes
Use `docker.df()` for sizes. Cleanup is the riskiest feature in v1.1: unit-test the exclusion logic and require typed confirmation for volumes.
