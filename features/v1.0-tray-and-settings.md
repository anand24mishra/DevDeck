# v1.0 — Menu bar, single instance, launch at login, settings

## Acceptance criteria
- [ ] Menu bar icon (template image, correct in light/dark) with: Open DevDeck, Stop all dev processes, Quit
- [ ] Popover or menu shows count of running dev processes
- [ ] Single-instance lock; second launch focuses the window
- [ ] Launch at login toggle (`app.setLoginItemSettings`)
- [ ] Settings: refresh rate, ignore list (add/remove names), extra allowlist names, Docker socket override, theme (system/light/dark)
- [ ] Settings validated on load; corrupt file falls back to defaults and logs the event
- [ ] Window state (size/position) remembered

## Technical notes
Electron `Tray` + `nativeImage` with `Template` suffix. Settings in `userData/settings.json`, schema-validated.
Do not register global hotkeys in v1.0 (v2).

## Design notes
Settings is one scrolling page with 4 short sections. No tabs inside settings.
