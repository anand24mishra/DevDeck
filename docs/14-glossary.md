# 14 — Glossary (plain words)

- **Process** — a program that is running right now.
- **PID** — the number the computer uses to identify a process.
- **Port** — a numbered door a program listens on (e.g. 3000 for a dev website).
- **Stop** — ask a process to quit politely (SIGTERM).
- **Force stop** — make it quit immediately (SIGKILL); used only if it ignores Stop.
- **Project** — the folder a process was started from, detected via its working directory.
- **Container** — an isolated app package run by Docker.
- **Compose project** — a group of containers started together from one file.
- **Socket (Docker)** — the file DevDeck uses to talk to Docker on your machine.
- **Zombie / orphan** — a leftover process whose parent is gone.
- **Profile** — a saved list of commands to start or stop a whole project stack.
- **Notarization** — Apple's check that lets a downloaded app open without warnings.
